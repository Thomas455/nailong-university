这个目录放各学院的**艺术作品**（展览馆里点开学院卡片看到的那些）。

一个学院一个子目录，目录名 = 学院名，和 src/ 的命名规则完全一样。

  works/经济与统计学院/
  works/法学院（律师学院）/
  works/管理学院（旅游学院·中法旅游学院）/    ← 注意中间是「·」不是「/」
  works/人工智能学院/
  …（共 25 个，已经建好了）

────────────────────────────────────────────────
作品怎么命名？两种来源**混着用**。
────────────────────────────────────────────────

【来源一】list.txt —— 精心排版的放这里，**优先展示**

  在学院目录里放一个 list.txt，一行一个文件名：

      奶龙在图书馆
      奶龙打篮球.webp
      奶龙参加开学典礼

  一行一个。**写在最下面的显示在最上面**（当成最新的），
  所以新作品追加到文件末尾即可。

  · 后缀 .webp 可写可不写，不写会自动补上
  · 以 # 开头的行当注释，空行忽略

【来源二】数字命名 —— 随手丢进来的，**排在清单后面**

  1.webp
  2.webp
  3.webp
  …

  页面从 1 开始探测，探测到断档就停。
  **编号大的显示在上面**（新的在前），所以新作品直接起个更大的编号就行。

【最终顺序】

  先列 list.txt 里的（按清单倒序），再接数字命名的（按编号倒序）。
  两边都有的只显示一次，位置以清单为准。

  举例：目录里有 1/2/3.webp 和 奶龙拿奖杯/奶龙做统计.webp，
  list.txt 写着：

      奶龙拿奖杯
      2.webp
      奶龙做统计

  最终显示顺序（5 件，2.webp 不会重复）：

      1. 奶龙做统计.webp     ← 清单最后一行
      2. 2.webp              ← 清单第 2 行
      3. 奶龙拿奖杯.webp     ← 清单第 1 行
      4. 3.webp              ← 编号补充，大的在前
      5. 1.webp

  一句话：想控制顺序就用 list.txt，懒得管就直接数字命名，两种都能用。

────────────────────────────────────────────────
注意
────────────────────────────────────────────────

· 只认 .webp。JPG / PNG 放进来不会被识别（转一下就好，能省很多体积）
· 作品按**文件名/清单顺序**排，不是按文件修改时间 —— 静态站点拿不到服务器时间
· 空目录里有一个 .gitkeep，那是为了让 git 能跟踪空目录，别删
· 图片建议竖版或正方形（列表里按 3:4 裁剪显示）
· 两种来源是**并行请求**的，所以有没有 list.txt 都不会变慢

────────────────────────────────────────────────
怎么预览
────────────────────────────────────────────────

  python -m http.server 8801
  然后打开 http://127.0.0.1:8801/show.html 点学院卡片

  必须用 http 方式 —— 页面靠 fetch 读文件，浏览器禁止 file:// 下的 fetch。
  双击本地打开时会显示「还没有作品」，那是浏览器的安全策略，不是坏了。
