这个目录放各学院的**艺术作品**（展览馆里点开学院卡片看到的那些）。

一个学院一个子目录，目录名 = 学院名，和 src/ 的命名规则完全一样。

  works/经济与统计学院/
  works/法学院（律师学院）/
  works/管理学院（旅游学院·中法旅游学院）/    ← 注意中间是「·」不是「/」
  works/人工智能学院/
  …（共 25 个，已经建好了）

────────────────────────────────────────────────
作品怎么命名？两种方式，任选其一。
────────────────────────────────────────────────

【方式一】数字命名（最省事）

  1.webp
  2.webp
  3.webp
  …

  页面从 1 开始探测，探测到断档就停。
  **编号大的显示在上面**（新的在前），所以新作品直接起个更大的编号就行。

【方式二】用 list.txt 保留自己的文件名

  在想保留原文件名的学院目录里，放一个 list.txt：

      奶龙在图书馆.webp
      奶龙打篮球.webp
      奶龙参加开学典礼.webp

  一行一个文件名。**写在最下面的显示在最上面**（当成最新的），
  所以新作品追加到文件末尾即可。以 # 开头的行当注释忽略。

  有 list.txt 就用 list.txt，没有才退回数字探测。

────────────────────────────────────────────────
注意
────────────────────────────────────────────────

· 只认 .webp。JPG / PNG 放进来不会被识别（转一下就好，能省很多体积）
· 作品按**文件名/清单顺序**排，不是按文件修改时间 —— 静态站点拿不到服务器时间
· 空目录里有一个 .gitkeep，那是为了让 git 能跟踪空目录，别删
· 图片建议竖版或正方形（列表里按 3:4 裁剪显示）

────────────────────────────────────────────────
怎么预览
────────────────────────────────────────────────

  python -m http.server 8801
  然后打开 http://127.0.0.1:8801/show.html 点学院卡片

  必须用 http 方式 —— 页面靠 fetch 读文件，浏览器禁止 file:// 下的 fetch。
  双击本地打开时会显示「还没有作品」，那是浏览器的安全策略，不是坏了。
