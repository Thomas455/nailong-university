# 投稿指南

感谢你给奶龙展览馆投稿！

## 三步搞定

**1. 把图片放进对应学院的文件夹**

```
works/经济与统计学院/
works/法学院（律师学院）/
works/管理学院（旅游学院·中法旅游学院）/    ← 中间是「·」，不是「/」
```

⚠️ 文件夹名必须和学院名**一字不差**（含全角括号）。25 个文件夹已经建好了，
直接往里放，别新建、别改名。

**2. 在同一个文件夹里编辑 `list.txt`，把你的文件名追加到末尾**

已经有的 `list.txt`（假设）：

```
奶龙拿奖杯.webp
奶龙做统计.webp
```

你加了一行之后：

```
奶龙拿奖杯.webp
奶龙做统计.webp
奶龙打篮球.webp        ← 你新加的在最后
```

**3. 提 PR**

标题写清楚学院和作品就行，比如「投稿：体育学院 3 件」。

---

## 为什么用 list.txt

**写在 `list.txt` 最下面的，显示在页面上最上面**（当最新的），所以新作品
一律追加到文件末尾。

页面上最终的顺序是「`list.txt` 里有的 → 其余按编号」，两边都有的只显示一次。

> **为什么不推荐用 `1.webp`、`2.webp` 这种编号命名？**
> 因为好几个人同时投稿时容易撞号 —— 你和我可能都会新建 `5.webp`，
> 两个 PR 就没法同时合。而 `list.txt` 只是各自加一行，冲突了好解（两行都留就行）。

## 图片要求

| 要求 | 说明 |
| --- | --- |
| **格式** | 只认 `.webp`。JPG / PNG 请先转一下 |
| **比例** | 竖图或正方形最好 —— 列表里按 3:4 裁剪显示 |
| **体积** | 建议每张 300KB 以内（webp q88 通常够用） |
| **内容** | 奶龙相关的艺术创作，别放无关图片 |

**怎么转 webp？**

* 在线工具：[squoosh.app](https://squoosh.app)（拖进去 → 选 WebP → 下载）
* 命令行：`magick input.png -quality 88 output.webp`（需要 ImageMagick）
* 也可以直接传 JPG/PNG，维护者会用脚本统一转（但转完文件名可能变化，
  那样你的 `list.txt` 就不准了，所以**最好自己先转**）

## 常见问题

**Q：文件名可以用中文吗？**
可以，随便起。因为有 `list.txt` 记录，页面不需要靠文件名猜。

**Q：`list.txt` 里写不写 `.webp` 后缀？**
都行。写 `奶龙打篮球` 会自动当成 `奶龙打篮球.webp`。

**Q：一个学院已经有很多作品了，我怎么排？**
按时间顺序追加到末尾就行（新的在下面）。不用去动别人的行。

**Q：可以给同一个学院投多件吗？**
可以，一行一件，一起追加到末尾。

**Q：提交后多久能看到？**
合并到主分支并部署后就能看到（通常几分钟）。本地想先看效果：

```bash
python -m http.server 8801
# 然后打开 http://127.0.0.1:8801/show.html
```

⚠️ 必须用 http 方式预览 —— 页面靠 `fetch` 读文件，浏览器禁止 `file://`
下的 fetch。双击本地打开会显示「还没有作品」，那是安全策略，不是坏了。
